WATER POTABILITY DATASET

## Project Overview
This project analyzes the **Water Potability dataset** to determine whether water is safe for drinking.  
The analysis is performed using Python in a Jupyter/Google Colab notebook.

The project focuses on:
- Data cleaning
- Handling missing values
- Exploratory Data Analysis (EDA)
- Understanding factors affecting water potability

## Tools and Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook / Google Colab

## Dataset
The dataset contains water quality metrics such as:

- pH
- Hardness
- Solids
- Chloramines
- Sulfate
- Conductivity
- Organic Carbon
- Trihalomethanes
- Turbidity
- Potability (Target variable)

## Steps Performed

### 1 Data Loading
The dataset was loaded using Pandas.

### 2 Data Cleaning
- Checked missing values
- Examined dataset structure
- Prepared data for analysis

### 3 Exploratory Data Analysis
- Summary statistics
- Feature analysis
- Grouping by potability

### 4 Insights
The analysis helps understand how different chemical properties influence whether water is potable or not.
